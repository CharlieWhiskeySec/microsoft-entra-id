# Microsoft Entra ID

Enterprise Microsoft Entra ID security projects built within the Charlie Whiskey Security Labs (CWSL) enterprise environment.

This repository documents the planning, implementation, validation, and documentation of identity and access management controls using Microsoft Entra ID. Rather than serving as a collection of lab exercises, these projects simulate how identity security would be designed and deployed within a production enterprise.

---

## Objectives

- Design and implement secure identity architectures
- Deploy enterprise identity security controls
- Build practical experience with Microsoft Entra ID
- Prepare for the Microsoft SC-300 certification through hands-on implementation
- Document real-world identity engineering projects

---

## Enterprise Security Initiatives

### 🔐 Administrative Access Baseline *(In Progress)*

Establishing foundational protections for privileged identities.

**Technologies**

- Microsoft Entra ID
- Conditional Access
- Role-Based Access Control (RBAC)
- Microsoft Authenticator
- Multi-Factor Authentication

**Current Progress**

- Administrative accounts created
- Security groups implemented
- Global Administrator role assigned through group membership
- Conditional Access baseline (CA-001) deployed in Report-only mode
